# WpfFoundation agent instructions

Read and follow both instruction files before working in this repository:

- [Common development rules](docs/agents/common-rules.md): architecture principles, dependency injection, SOLID, C# and XAML style, testing, and refactoring.
- [WpfFoundation-specific rules](docs/agents/wpffoundation-rules.md): library boundaries, public API and resource keys, Fluent styling, dialogs, the Gallery, and packaging.

The WpfFoundation-specific rules specialize the common rules for this library. The staged implementation plan is documented in [docs/implementation-plan.md](docs/implementation-plan.md).
